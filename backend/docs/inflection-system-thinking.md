# 拐点与锚定物识别：思路与推导记录

## 1. 文档目的

本文记录为什么要这样设计拐点识别系统，以及从会议纪要中提炼出的核心判断。

它与技术设计分开：

- 本文回答“为什么这样理解”；
- [`inflection-system-design.md`](./inflection-system-design.md) 回答“程序如何实现”；
- [`inflection-engine.md`](./inflection-engine.md) 记录当前V1字段和接口。

主要素材来自腾讯会议转写文件《文字转写_骏也迪的快速会议_616789921.docx》。原文为机器转写，股票名称、数字和重复语句可能存在识别错误。

## 2. 最核心的结论

拐点不是某一根K线、某一次涨停或某一个固定价格。

拐点是一种关系变化：

```text
旧共识正在失效
      +
旧方向释放资金或影响力
      +
新方向首先表现主动
      +
环境不再继续恶化或开始改善
```

因此程序不能只扫描“谁涨停”，而要同时回答：

1. 谁代表旧共识？
2. 旧共识是被动受挫还是主动失效？
3. 市场环境发生了什么变化？
4. 释放出来的资金正在流向谁？
5. 新标的只是随机弹性，还是正在形成新共识？

## 3. 为什么必须先找锚定物

任何“强”和“弱”都是相对概念。

一只股票下跌3%：

- 如果市场下跌5%，它可能仍然主动偏强；
- 如果市场上涨2%，它可能已经主动走弱。

一只股票涨停：

- 如果只是指数普涨中的孤立跟随，不一定是拐点；
- 如果市场连续分歧后它率先主动涨停，含义完全不同。

没有环境锚和旧共识锚，程序只能描述价格，不能判断拐点。

## 4. 锚点不等于交易对象

这是整套思路最容易被误解的地方。

锚点的作用是提供判断参照，不一定值得买，也不一定可以买。

例如会议中的德明利：

- 它代表旧周期极端负反馈；
- 它开板意味着旧负反馈释放流动性；
- 但真正率先主动的可能是AI应用、智能驾驶或其他科技核心；
- 因此德明利可以是确认大拐点的锚，却不是新方向买入对象。

相反，某些低位股票可能被交易，但没有足够辨识度，不能承担整个板块或市场的锚点功能。

## 5. 四类观察对象

### 5.1 环境锚

环境锚判断个股或板块表现是主动还是被动。

可能包括：

- 指数；
- 全市场上涨、下跌家数；
- 市场涨停和跌停状态；
- 板块整体表现；
- 同一批核心股票的平均表现。

### 5.2 旧赚钱效应锚

它代表上一阶段资金是否仍愿意围绕旧核心交易。

会议中的恒尚节能承担这一角色：

- 周五被市场拖累炸板，不足以说明旧方向结束；
- 周一弱市逆势反包，说明资金仍愿意围绕它做文章；
- 周二开盘主动不及预期，才说明原赚钱效应开始出现裂缝。

### 5.3 旧负反馈锚

它代表上一周期是否充分出清。

会议中的德明利承担这一角色：

- 连续负反馈让参与者普遍痛苦；
- 开板或大量换手释放流动性；
- 但其打开通常是市场先改善后的结果，不一定是最早触发器。

### 5.4 新承接物

新承接物是旧方向释放资金后率先表现主动的对象。

它从“候选承接物”升级为“新锚点”需要：

- 足够辨识度；
- 主动而非被动上涨；
- 板块或同类跟随；
- 持续兑现其市场地位。

## 6. 辨识度的含义

会议对辨识度的朴素定义接近：问十个人，有多少人知道它、承认它的市场地位。

程序无法直接询问十个人，因此需要代理指标：

- 连板或阶段高度；
- 成交额和换手；
- 近期强势持续性；
- 板块带动和中心性；
- 弱市抗跌；
- 历史市场记忆。

辨识度不是“今天涨得最多”。它强调持续的公共认知。

如果第一名和第二名差距很小，最诚实的结论不是强行选一个，而是标记“锚点模糊”。

## 7. 大拐点的思路

大拐点不是涨幅大，而是结构变化范围大、旧周期出清更完整、新共识更清晰。

### 7.1 大拐点的结构

```text
连续且充分的市场分歧
          +
旧赚钱效应或负反馈核心完成出清
          +
市场/板块环境由恶化转向改善
          +
新核心率先主动并获得跟随
```

### 7.2 大拐点中的时间顺序

最重要的不是“旧负反馈锚打开”这个结果，而是谁在它打开之前已经开始主动。

会议认为德明利本身没有主动性：

- 市场和新科技方向先改善；
- 德明利才可能被撬开；
- 等完全开板后再寻找新方向，核心可能已经无法买入。

所以大拐点识别必须保存事件顺序，而不能只使用日终状态。

### 7.3 会议中的大拐点模板

#### 德明利模板

- 旧负反馈锚：德明利；
- 环境锚：市场和科技整体情绪；
- 新承接物：率先主动的科技细分核心；
- 旧锚开板：确认旧负反馈释放。

该场景在会议中主要是预期和推演，并非所有条件已经发生。

#### 东山精密模板

- 背景：市场经历连续分歧；
- 环境：周二上午仍弱；
- 新承接物：东山精密先抗跌、后主动涨停；
- 作用范围：市场大势和科技大容量方向。

该案例更接近已经出现的市场/板块范围转折。

## 8. 小拐点的思路

小拐点不是“小涨幅”，而是：

- 旧共识只出现裂缝，尚未完全出清；
- 新方向仍处于尝试；
- 作用范围较局部；
- 判断更依赖经验和提前量；
- 首要预期通常是次日溢价，而非完整新周期。

### 8.1 高低切小拐点

会议中恒尚节能开始主动走弱后，资金尝试智度、哈药、香江控股、道明光学等低位方向。

这里：

- 恒尚是旧赚钱效应锚；
- 市场和情绪风格是环境锚；
- 低位股票是新承接候选；
- 这些低位候选不一定已经获得新锚点地位。

### 8.2 个股自身小拐点

恒尚节能周五被动炸板、周一弱市逆势反包，构成个股相对于自身和环境的拐点。

它不需要另一只旧锚，因为对照的是：

- 个股上一状态；
- 当前环境；
- 个股当日主动修复。

但周二开盘不及预期，说明这个小拐点没有升级为更大周期。

### 8.3 极小、随机性强的尝试

南极电商案例表明：

- 高位核心出现跌停；
- 主讲人主观寻找非科技低位首板；
- 低位没有明确核心；
- 选股存在随机性；
- 因此仓位很小，次日跌破均线即退出。

这类信号应被标记为“低置信度尝试”，不能与清晰的大拐点使用同一套预期。

## 9. 主动与被动是连接锚点和拐点的桥梁

### 9.1 被动走弱

被动走弱意味着：

- 市场或板块突然恶化；
- 个股被整体拖累；
- 个股相对环境仍有抗性；
- 原共识可能还未结束。

如果把被动炸板直接解释成旧锚失效，就会过早进行高低切。

### 9.2 主动走弱

主动走弱意味着：

- 市场改善，旧核心反而变弱；
- 前一日已经“亮剑”，次日却严重低于预期；
- 旧核心不再承担其应有的市场地位；
- 资金开始寻找其他方向。

因此程序必须使用相对环境表现，而不是只看绝对涨跌幅。

## 10. “预期拐点”不等于“拐点已经发生”

会议中周五提前买入智度、星网锐捷等，是因为认为德明利对应的大拐点可能临近。

随后主讲人承认拐点没有如期出现，交易可能判断错误。

这给程序设计带来一个明确要求：

```text
candidate != confirmed
```

- `candidate`：条件正在接近，仍属于提前量；
- `confirmed`：旧锚、环境、新承接物的独立门槛都已经满足。

不能因为综合分高，就把缺少关键结构条件的信号升级为确认。

## 11. 锚点清晰度为什么必须单独处理

会议强调只能用地位最高的对象锚定，老二都不行。

“万邦”案例揭示了两个层次：

- 它可以作为与指数反向变化的交易物；
- 但它没有资格承担整个医药或市场方向的核心锚点；
- 医药内部更适合用辨识度更高的哈药等对象观察。

因此需要区分：

```text
观察锚点 != 交易对象
```

程序应同时输出锚点和候选承接物，不能只返回一只“推荐股票”。

## 12. 从会议观点到程序字段

| 会议语言 | 程序代理 |
| --- | --- |
| 所有人都知道、市场地位最高 | `recognition` |
| 市场连续分歧、所有人很难受 | `market_stress_score` |
| 被大盘拖累 | 相对环境收益、`previous_passive_weak` |
| 主动走弱 | `active_weakness_score` |
| 率先主动、打板确认 | `active_strength_score`、`limit_up` |
| 旧周期出清 | `clearance_score` |
| 市场开始转好 | `environment_turn_score` |
| 大拐点临近 | `big.status=candidate` |
| 大拐点发生 | `big.status=confirmed` |
| 高低切尝试 | `small.setup=high_low_switch` |
| 个股自身逆势修复 | `small.setup=individual_reversal` |
| 买入预期被破坏 | `expectation_gap_percent` |

## 13. 当前设计中的人为假设

以下内容不是会议直接给出的精确数字，而是为了让程序先跑起来而设置的V1假设：

- 各因子的默认权重；
- 辨识度阈值；
- 第一名和第二名的最小分差；
- 大、小拐点候选和确认阈值；
- 相对环境收益中市场、板块各占一半；
- 涨跌幅达到多少时映射到满分；
- 跟随股票数量的满分范围。

这些值必须被视为可配置研究参数，而不是会议结论或固定交易真理。

## 14. 不能被量化掩盖的主观部分

即使完成量化，仍有一些问题需要人为或更高级模型判断：

- 当前市场真正交易的主线是什么？
- 两只高辨识度股票代表的是同一共识还是不同共识？
- 一次涨停是板块主动，还是单一消息脉冲？
- 新承接物是否具有可持续叙事？
- 当多个层级同时出现拐点时，哪个层级优先？
- 新闻和业绩催化是否改变原有预期？

量化的作用是减少随意解释、保存证据和复现判断，不是消灭所有主观性。

## 15. 研究中必须防止的偏差

### 15.1 事后选择锚点

必须使用信号产生时已经存在的辨识度数据，不能根据后续涨幅重选锚点。

### 15.2 只保留成功案例

所有候选、确认、失败和无信号日都要保存。

### 15.3 成交幻觉

一字涨停、涨停排队、跌停无法卖出必须进入回放。

### 15.4 参数过拟合

不能在完整历史样本上选择最佳参数，再用同一批数据证明有效。

### 15.5 把相关性解释为资金因果

旧锚走弱和新方向上涨同时发生，不一定证明资金从A直接流向B。程序输出应使用“承接候选”而不是无证据的确定因果。

## 16. 评价策略是否有效的标准

不应只看胜率，还需要：

- 候选到确认的转化率；
- 大、小拐点分别的可成交率；
- 次日、三日、五日收益分布；
- 盈亏比；
- 最大回撤；
- 连续失败次数；
- 锚点模糊时的表现；
- 主动走弱与被动走弱分类准确度；
- 不同市场环境下的稳定性；
- 信号产生到可成交之间的时间差。

## 17. 当前阶段的判断

V1的价值不是已经证明赚钱，而是完成了三个基础转换：

1. 把“拐点”从一句口诀变成旧锚、环境、新承接物的关系；
2. 把“预期会拐”和“已经拐了”分成候选与确认；
3. 把每次结论拆成可保存的因子、证据和风险。

下一步的核心不是继续增加主观规则，而是接入历史和分钟数据，观察这些定义在真实失败样本中是否仍然成立。
