# 拐点交易回测方案（按会议纪要拆分）

图片中的“拐点”不是一个二分类信号，而是多个层级、多个触发原因的组合。回测结果必须保留具体类型，不能只显示“大/小”。

| 类型 | 层级 | 识别重点 | 典型失效 |
| --- | --- | --- | --- |
| `market_exhaustion` 市场出清大拐点 | 市场 | 连续亏钱、跌停/炸板压力见顶，旧锚主动走弱，宽度和跌停反馈改善，新方向出现清晰承接 | 压力未释放、旧核心仍强、新方向只有跟风 |
| `sentiment_repair` 情绪修复拐点 | 市场/题材 | 冰点后负反馈收敛，昨日强势股溢价回升，涨停晋级率和宽度改善 | 只有指数反弹，短线反馈继续恶化 |
| `high_low_switch` 高低切小拐点 | 题材/个股 | 高位旧核心走不动，低位新方向出现主动进攻和扩散 | 高位只是正常分歧，低位没有持续性 |
| `sector_rotation` 题材/板块拐点 | 题材 | 资金净流向、板块相对收益、上涨家数和核心辨识度同步转强 | 单只股票上涨，板块没有跟随 |
| `individual_reversal` 个股反转拐点 | 个股 | 个股此前相对板块是被动走弱，当前相对收益、VWAP 和量价转为主动 | 反弹来自指数 beta，个股相对强度没有改善 |
| `trend_reversal` 趋势拐点 | 个股/题材 | 中期高低点、均线斜率、波动收缩后放量突破，且相对行业强度确认 | 突破无量、次日跌回关键位 |
| `index_reversal` 指数拐点 | 市场 | 指数相对 VWAP、宽度、成交额和风险偏好同时改善 | 指数被权重股拉升，市场宽度不跟 |
| `expectation_gap` 预期差拐点 | 任意层级 | 竞价/开盘表现与前一日一致预期出现差异，并被资金主动确认 | 预期差不能持续，收盘回落或无法成交 |

实现上，每个交易日先计算市场、题材、个股特征，再生成一个或多个 `TurningPointKind`。信号在 `t` 日收盘确认，最早在 `t+1` 开盘成交。回测必须记录信号类型、触发因子、失效条件和成交可得性，方便分别统计每种拐点的收益、胜率、回撤和持有期。

代码中的类型定义位于 `backend/internal/strategy/inflection/types.go`，分类结果通过 `SignalEvaluation.Kinds` 返回。
