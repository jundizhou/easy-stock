# 龙虎榜席位映射说明

`frontend/src/data/billboard-seat-mappings.ts` 是 easy-stock 的龙虎榜席位辅助映射表，用于在连板梯队和行情总览的龙虎榜弹窗中显示“机构 / 游资 / 量化 / 活跃资金”等标签。

## 三个数据源的口径

| 数据源 | 当前可确认的信息 | 项目使用方式 |
| --- | --- | --- |
| 东方财富 | 原始营业部名称、`机构专用`、买卖金额、上榜原因、买卖席位 | 当前后端直接接入的龙虎榜明细主数据源 |
| 同花顺 | 龙虎榜个股明细、热门营业部、机构席位，以及“知名游资 / 敢死队 / 游资上榜”等统计分类 | 用于校对分类口径和维护席位映射；不直接依赖其登录态 |
| 开盘啦 | 涨停池、连板梯队、题材和龙头信息 | 当前项目用于连板和题材；公开页面未发现稳定可复用的龙虎榜席位身份字段 |

参考入口：

- 东方财富龙虎榜：[data.eastmoney.com/stock/lhb.html](https://data.eastmoney.com/stock/lhb.html)
- 同花顺龙虎榜：[data.10jqka.com.cn/market/longhu](https://data.10jqka.com.cn/market/longhu/)
- 开盘啦：[kaipanla.com](https://www.kaipanla.com/)

## 映射原则

1. `institution: true` 或原始名称包含“机构专用 / 机构席位”时，优先标为“机构”，置信度为高。
2. 具体游资名称与营业部的对应，是公开市场长期使用的常用映射，不是监管或券商对真实操盘人的身份确认。
3. 同一营业部可能被不同资金使用，席位也可能迁移；因此映射只作为阅读辅助，不能用于断言“某人正在交易”。
4. “量化”只在原始数据或公开文本明确出现量化/算法标签时标高置信度；像华鑫上海分公司这类常见候选席位仅标为低置信度“量化/活跃资金”。
5. 拉萨多家营业部统一标为“活跃资金 · 拉萨席位集群”，不直接等同于全部散户。
6. 未匹配席位统一显示“未识别”，并在悬浮提示中说明无法仅凭营业部名称确认资金身份。
