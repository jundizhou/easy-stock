# 龙虎榜席位映射说明

`frontend/src/data/billboard-seat-mappings.ts` 是 easy-stock 的龙虎榜席位辅助映射表，用于在连板梯队和行情总览的龙虎榜弹窗中显示“机构 / 游资 / 量化 / 活跃资金”等标签。

## 三个数据源的口径

| 数据源 | 当前可确认的信息 | 项目使用方式 |
| --- | --- | --- |
| 东方财富 | 原始营业部名称、`机构专用`、买卖金额、上榜原因、买卖席位 | 当前后端直接接入的龙虎榜明细主数据源 |
| 同花顺 | 龙虎榜个股明细、热门营业部、机构席位，以及“一线游资 / 知名游资”等公开分类 | 后端按交易日动态抓取公开龙虎榜页面，以标准化营业部名称合并标签；失败时自动降级 |
| 开盘啦 | 涨停池、连板梯队、题材和龙头信息 | 当前项目用于连板和题材；公开页面未发现稳定可复用的龙虎榜席位身份字段 |

参考入口：

- 东方财富龙虎榜：[data.eastmoney.com/stock/lhb.html](https://data.eastmoney.com/stock/lhb.html)
- 同花顺龙虎榜：[data.10jqka.com.cn/market/longhu](https://data.10jqka.com.cn/market/longhu/)
- 开盘啦：[kaipanla.com](https://www.kaipanla.com/)

## 映射原则

1. 东方财富原始席位数据负责名称和金额；同花顺公开页面标签作为动态增强，优先于本地静态映射，并记录来源与置信度。
2. `institution: true`、原始名称包含“机构专用 / 机构席位”或同花顺明确标注机构时，优先标为“机构”，置信度为高。
3. 具体游资名称与营业部的对应，是公开市场长期使用的常用映射，不是监管或券商对真实操盘人的身份确认。
4. 同一营业部可能被不同资金使用，席位也可能迁移；因此映射只作为阅读辅助，不能用于断言“某人正在交易”。
5. “量化”只在原始数据或公开文本明确出现量化/算法标签时标高置信度；像华鑫上海分公司这类常见候选席位仅标为低置信度“量化/活跃资金”。同花顺 App 内的“量化基金 / 量化打板”细分标签目前不在公开网页字段中，不能通过营业部名称强行推断。
6. 拉萨多家营业部统一标为“活跃资金 · 拉萨席位集群”，不直接等同于全部散户。
7. 未匹配时不显示猜测标签，保留完整营业部名称供悬浮查看。
