# easy-stock 最短配置指南

打开 easy-stock 后，只需完成两件事：**配置大模型**，以及按需**登录雪球或淘股吧**。

## 一、购买大模型 API

> 网页版或 App 会员不等于 API 余额，需要在开放平台单独充值。

### 方案一：DeepSeek

1. 登录 [DeepSeek 开放平台](https://platform.deepseek.com/)。
2. 进入费用中心，小额充值 API 余额。
3. 进入 API Keys 页面，创建并复制 API Key。

### 方案二：Kimi

1. 登录 [Kimi 开放平台](https://platform.kimi.com/console)。
2. 进入费用中心，小额充值 API 余额。
3. 进入 API Key 管理页面，创建并复制 API Key。

### 方案三：其他模型

MiniMax、智谱 GLM、通义千问、硅基流动等也可以使用。前往对应开放平台注册、充值并创建 API Key 即可。

## 二、在 easy-stock 中配置模型

打开「**系统设置 → Hermes 模型运行时**」，点击「新增配置」。

| 服务商 | API Base URL | 模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-v4-pro`（或更快的 `deepseek-v4-flash`） |
| Kimi（月之暗面） | `https://api.moonshot.cn/v1` | 点击「获取模型」选择 |

接口协议选择 `Chat Completions`，粘贴 API Key，然后点击「**保存并测试连接**」。看到「Hermes 模型连接可用」即配置成功。

其他服务商直接在列表中选择；列表中没有时，可选择「OpenAI 兼容接口」，按照服务商官方文档填写地址和模型。

## 三、登录雪球或淘股吧

打开「**系统设置 → 大V复盘自动化**」：

1. 选择「雪球」或「淘股吧」。
2. 点击「添加配置」，填写名称和同步时间。
3. 保持默认平台地址，点击底部「保存设置」。
4. 点击「打开登录窗口」，在官方页面完成登录和验证码。
5. 点击窗口右下角「我已完成登录」。

显示「雪球浏览器已登录」或「淘股吧浏览器已登录」即完成。登录过期后点击「重新登录」即可，不需要手工复制 Cookie。

## 四、添加大V订阅

1. 复制雪球或淘股吧作者的**主页地址**。
2. 打开「**大V复盘日记 → 原文资料 → 自动订阅与每日同步**」。
3. 选择平台和刚才保存的登录配置，粘贴主页地址。
4. 点击「添加订阅」，再点「立即同步」。

以后 easy-stock 会按设置的时间自动检查新文章。

## 五、同步知识星球（可选）

知识星球的内容读取权限由**星主按星球开通**，成员身份不自带。未开通的星球会提示「该星球尚未开通 Skill 权限」，需要在星球里联系星主申请开通。

### 1. 安装命令行工具

1. 准备 Node.js 18 或更高版本，再安装官方命令行工具：`npm install -g zsxq-cli`。easy-stock 通过它读写数据，两者都是必需的前置条件；没装时该来源会显示为不可用，不影响其他来源。
2. 打开「系统设置 → 数据源 → 知识星球」，点「扫码授权」，用知识星球 App 扫页面上的二维码确认。凭据由官方 CLI 写入系统钥匙串，easy-stock 不保存 token；页面不需要安装终端或粘贴任何密钥。

二维码有效期 10 分钟，过期后重新点「扫码授权」即可。也可以在终端执行 `zsxq-cli auth login` 完成同样的授权，重新打开设置页就会显示为已授权。

### 2. 添加星球订阅

1. 确认「知识星球默认配置」已启用，同步时间默认每天 07:00，同一配置下的星球共用这个时间。
2. 打开「**大V复盘日记 → 原文资料 → 自动订阅与每日同步**」，平台选择「知识星球」。
3. 点「检测我的星球」，可同步的星球会标为「可同步」，其余标为「需星主开通」。
4. 点选一个可同步的星球（会自动填入链接），再点「添加订阅」和「立即同步」。

同一个星球里的不同发帖人会各自成为独立作者，不会合并成一位；星主本人和主力发帖人通常不是同一个账号。合并会让「共识」和「分歧」的归纳失真，所以这里按发帖账号拆分。

### 3. 同步范围

- **首次同步**取最近 **48 小时**的主题，之后按「上次成功同步时间前推 6 小时」取值，重叠部分按主题 ID 去重。同步失败时保留已采到的内容，不推进成功时间；恢复后再次同步会补采未完成的范围。
- 单次最多读取 **8 页**。如果达到上限仍未覆盖时间窗，或后续分页失败，页面会提示「同步未完成」，不会把部分结果记为完整成功。
- 正文短于 **8 个字符**的主题会跳过：一句话点评对观点归纳没有信息量，留在列表里只会稀释作者卡。
- 48 小时之外的历史**不会回填**。想要更长的历史，目前需要等后续版本提供「首次回填天数」设置。

星球主题的原始富文本（`<e>` 链接、标签等）会在入库前转成纯文本，正文中的外链保留为「标题 (地址)」形式，方便回到原文核对。

### 4. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 来源显示「受限」并提示「未找到 zsxq-cli」 | 没找到 `zsxq-cli` 或 Node | 确认 `node -v` 可用，再执行 `npm install -g zsxq-cli`，重启应用 |
| 点「扫码授权」后一直等待 | 二维码已过 10 分钟有效期 | 重新点「扫码授权」生成新二维码 |
| 星球标为「需星主开通」 | 内容接口需要星主在星球后台开通 Skill 权限 | 在星球里联系星主申请，开通后点「检测我的星球」重新探测 |
| 同步成功但条数比 App 里少 | 超出 48 小时窗口，或正文过短被跳过 | 属预期行为，见上一节 |
| 同步后又点一次「立即同步」，新增为 0 | 按主题 ID 去重 | 属正常，没有新帖时就是 0 |

## 遇到问题

- 提示 401/403：检查 API Key 和 API 余额。
- 提示模型不存在：重新点击「获取模型」并选择可用模型。
- 登录识别失败：确认网页已真正登录并完成验证码，再点击「我已完成登录」。
- 仍无法解决：进入「系统设置 → 运行日志 → 打开日志目录」，将日志提供给开发者。

请勿公开 API Key、账号密码或验证码。模型密钥和雪球、淘股吧登录状态均保存在本机。
