# easy-stock 最短配置指南

打开 easy-stock 后，只需完成两件事：**配置大模型**，以及按需**登录雪球或淘股吧**。

## 一、购买大模型 API

> 网页版或 App 会员不等于 API 余额，需要在开放平台单独充值。

### 方案一：DeepSeek

1. 登录 [DeepSeek 开放平台](https://platform.deepseek.com/)。
2. 进入费用中心，小额充值 API 余额。
3. 进入 API Keys 页面，创建并复制 API Key。

### 方案二：Kimi

1. 登录 [Kimi 开放平台](https://platform.kimi.com/console)。
2. 进入费用中心，小额充值 API 余额。
3. 进入 API Key 管理页面，创建并复制 API Key。

### 方案三：其他模型

MiniMax、智谱 GLM、通义千问、硅基流动等也可以使用。前往对应开放平台注册、充值并创建 API Key 即可。

## 二、在 easy-stock 中配置模型

打开「**系统设置 → Hermes 模型运行时**」，点击「新增配置」。

| 服务商 | API Base URL | 模型 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| Kimi（月之暗面） | `https://api.moonshot.cn/v1` | 点击「获取模型」选择 |

接口协议选择 `Chat Completions`，粘贴 API Key，然后点击「**保存并测试连接**」。看到「Hermes 模型连接可用」即配置成功。

其他服务商直接在列表中选择；列表中没有时，可选择「OpenAI 兼容接口」，按照服务商官方文档填写地址和模型。

## 三、登录雪球或淘股吧

打开「**系统设置 → 大V复盘自动化**」：

1. 选择「雪球」或「淘股吧」。
2. 点击「添加配置」，填写名称和同步时间。
3. 保持默认平台地址，点击底部「保存设置」。
4. 点击「打开登录窗口」，在官方页面完成登录和验证码。
5. 点击窗口右下角「我已完成登录」。

显示「雪球浏览器已登录」或「淘股吧浏览器已登录」即完成。登录过期后点击「重新登录」即可，不需要手工复制 Cookie。

## 四、添加大V订阅

1. 复制雪球或淘股吧作者的**主页地址**。
2. 打开「**大V复盘日记 → 原文资料 → 自动订阅与每日同步**」。
3. 选择平台和刚才保存的登录配置，粘贴主页地址。
4. 点击「添加订阅」，再点「立即同步」。

以后 easy-stock 会按设置的时间自动检查新文章。

## 遇到问题

- 提示 401/403：检查 API Key 和 API 余额。
- 提示模型不存在：重新点击「获取模型」并选择可用模型。
- 登录识别失败：确认网页已真正登录并完成验证码，再点击「我已完成登录」。
- 仍无法解决：进入「系统设置 → 运行日志 → 打开日志目录」，将日志提供给开发者。

请勿公开 API Key、账号密码或验证码。模型密钥和雪球、淘股吧登录状态均保存在本机。

> easy-stock 仅用于学习、研究和信息整理，不构成任何投资建议。
