# easy-stock 使用帮助

本文面向下载安装 easy-stock 桌面版的普通用户，介绍首次使用时最常见的两项配置：

- 购买国内大模型 API 额度、创建 API Key，并在 easy-stock 中完成连接。
- 在 easy-stock 中登录雪球或淘股吧，让「大V复盘日记」自动同步已订阅作者的文章。

> easy-stock 不提供大模型额度，也不会代替你注册第三方平台账号。大模型费用由服务商按实际 API 用量收取，雪球和淘股吧账号则由对应平台管理。

## 下载与首次启动

1. 打开 [easy-stock GitHub Releases](https://github.com/jundizhou/easy-stock/releases/latest)。
2. 下载适合自己电脑的安装包：
   - Apple 芯片 Mac（M1、M2、M3、M4 等）：选择文件名带 `macos-arm64` 的 DMG。
   - Intel 芯片 Mac：选择文件名带 `macos-x64` 的 DMG。
   - 64 位 Windows：选择文件名带 `windows-x64-setup` 的安装程序。
3. macOS 打开 DMG 后，将 easy-stock 拖入「应用程序」；Windows 打开安装程序并按提示完成安装。
4. 启动 easy-stock。普通用户不需要另外安装 Node.js、Go 或 Python。

如果不确定 Mac 使用哪种芯片，可打开左上角苹果菜单，选择「关于本机」，查看“芯片”或“处理器”一栏。

## 配置大模型前先了解这些

easy-stock 的 AI 对话、个股分析、持仓巡检和复盘提炼等功能，需要调用你自行选择的大模型 API。这里有两个容易混淆的概念：

- **网页或手机 App 会员**：用于服务商自己的聊天产品。
- **开放平台 API 余额**：用于 easy-stock 这类第三方应用调用模型。

购买 Kimi 或 DeepSeek 的网页/App 会员，通常不代表 API 账户已有余额。请进入对应的开放平台单独开通并充值 API 额度。各平台价格可能调整，实际计费方式和价格以服务商官方页面为准。

完整流程都是：

1. 注册并登录大模型开放平台。
2. 按平台提示完成实名认证或其他必要验证。
3. 在开放平台的费用中心充值 API 额度。
4. 创建 API Key 并妥善保存。
5. 回到 easy-stock 填写模型配置，执行「保存并测试连接」。

你只需要把 **API Key** 填入 easy-stock，不要填写大模型平台的登录密码。

## 方案一：配置 DeepSeek

### 1. 注册并购买 API 额度

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册或登录账号。
2. 如果平台提示需要认证，请按页面要求完成认证。
3. 进入「费用中心」「余额充值」或名称相近的页面，根据自己的使用量充值 API 额度。
4. 可在 [DeepSeek API 文档](https://api-docs.deepseek.com/) 查看最新模型、计费和接口说明。

建议先小额充值并完成连接测试，再根据实际使用量追加。AI 长报告、持仓巡检和批量文章提炼通常比简短对话消耗更多额度。

### 2. 创建 DeepSeek API Key

1. 在 DeepSeek 开放平台进入「API Keys」或「API 密钥」页面。
2. 点击创建新的 API Key，并填写一个容易识别的名称，例如 `easy-stock`。
3. 创建后立即复制并保存在安全位置。API Key 通常只会完整显示一次，关闭页面后可能无法再次查看。

### 3. 在 easy-stock 中配置

1. 打开 easy-stock，点击左侧栏底部的「系统设置」。
2. 找到「Hermes 模型运行时」。
3. 使用现有模型配置，或点击「新增配置」。
4. 按下表填写：

| 配置项 | 建议填写 |
| --- | --- |
| 配置名称 | `DeepSeek 日常` |
| 服务商 | `DeepSeek` |
| 接口协议 | `Chat Completions` |
| API Base URL | `https://api.deepseek.com` |
| 模型 API Key | 粘贴刚创建的 DeepSeek API Key |
| 模型 | `deepseek-chat` |
| 模型响应等待时间 | 保持默认 `300` 秒 |

5. 可以点击「获取模型」刷新可用模型，也可以直接使用上表中的模型名。
6. 点击「保存并测试连接」。
7. 页面显示「Hermes 模型连接可用」，说明配置成功。

`deepseek-chat` 适合先用于日常分析。如果以后改用其他 DeepSeek 模型，请以开放平台当前提供的模型列表和计费说明为准。

## 方案二：配置 Kimi

Kimi 的 API 服务由月之暗面开放平台提供。请在开放平台购买 API 额度，不要把 Kimi 网页版或手机 App 的会员当作 API 余额。

### 1. 注册并购买 API 额度

1. 打开 [Kimi 开放平台控制台](https://platform.kimi.com/console)，注册或登录账号。
2. 如果平台提示需要认证，请按页面要求完成认证。
3. 在控制台进入「费用中心」「充值」或名称相近的页面，购买 API 额度。
4. 可在 [Kimi 开放平台文档](https://platform.kimi.com/docs/overview) 查看当前可用模型、上下文长度、计费和限流规则。

建议先小额充值并完成连接测试。Kimi 聊天产品中的会员权益与开放平台 API 账户通常分开计算。

### 2. 创建 Kimi API Key

1. 在 Kimi 开放平台控制台进入「API Key 管理」或名称相近的页面。
2. 点击新建 API Key，并填写一个容易识别的名称，例如 `easy-stock`。
3. 创建后立即复制并妥善保存。不要将完整 Key 放入聊天记录、截图、Issue 或公开文档。

### 3. 在 easy-stock 中配置

1. 打开 easy-stock，点击左侧栏底部的「系统设置」。
2. 找到「Hermes 模型运行时」。
3. 使用现有模型配置，或点击「新增配置」。
4. 按下表填写：

| 配置项 | 建议填写 |
| --- | --- |
| 配置名称 | `Kimi 日常` |
| 服务商 | `Kimi（月之暗面）` |
| 接口协议 | `Chat Completions` |
| API Base URL | `https://api.moonshot.cn/v1` |
| 模型 API Key | 粘贴刚创建的 Kimi API Key |
| 模型 | 优先点击「获取模型」选择账号当前可用的模型 |
| 模型响应等待时间 | 保持默认 `300` 秒 |

5. 点击「获取模型」，从列表中选择当前账号可用的模型。
6. 如果暂时无法获取列表，可先手动填写 `moonshot-v1-8k`，再测试该模型当前是否可用。
7. 点击「保存并测试连接」。
8. 页面显示「Hermes 模型连接可用」，说明配置成功。

服务商可能调整模型名称或下线旧模型，因此 Kimi 配置优先以「获取模型」返回的结果为准。

## 方案三：配置其他模型

除了 DeepSeek 和 Kimi，easy-stock 还内置支持 MiniMax、智谱 GLM、通义千问（百炼）和硅基流动等国内模型服务。你可以自行选择服务商，在其官方开放平台注册、充值并创建 API Key，然后进入「系统设置 → Hermes 模型运行时」，点击「新增配置」：

1. 选择对应服务商并填写 API Key。
2. 保留软件自动填写的接口协议和 API Base URL，或以服务商最新官方文档为准。
3. 点击「获取模型」选择账号当前可用的模型。
4. 点击「保存并测试连接」，显示「Hermes 模型连接可用」即可。

如果使用的是列表中没有、但提供 OpenAI 兼容接口的国内服务商，可选择「OpenAI 兼容接口」，再按照其官方文档填写 API Base URL、模型名和 API Key。

## 切换或增加模型配置

easy-stock 支持保存多套模型配置。例如，可以同时保存 `DeepSeek 日常` 和 `Kimi 日常`：

1. 进入「系统设置 → Hermes 模型运行时」。
2. 点击「新增配置」，为另一家服务商填写独立的 Base URL、API Key 和模型。
3. 每套配置都单独执行一次「保存并测试连接」。
4. 通过「模型配置」下拉框选择当前使用的配置。

切换配置不会覆盖其他配置的密钥。已经保存的密钥不会在页面中重新显示明文；输入新值会覆盖旧 Key，留空则保留原值。

## 绑定并登录雪球

雪球登录窗口只在 easy-stock 桌面版中提供。操作前请先确认你能在雪球官方网页正常登录自己的账号。

1. 打开 easy-stock，点击左侧栏底部的「系统设置」。
2. 找到「大V复盘自动化」，选择「雪球」标签。
3. 如果还没有配置，点击「添加雪球配置」。
4. 填写配置名称，例如 `我的雪球账号`，选择每日同步时间，并保持配置为「已启用」。
5. 平台地址保持默认的 `https://xueqiu.com`。
6. 点击设置窗口底部的「保存设置」。
7. 再次进入该雪球配置，点击「打开登录窗口」。
8. 在弹出的雪球官方页面中，由你亲自完成账号登录、验证码或安全验证。
9. 确认网页已经登录后，点击登录窗口右下角的「我已完成登录」。
10. 检测成功后，按钮会显示「登录态已保存」，窗口随后自动关闭。
11. 回到系统设置，看到「雪球浏览器已登录」即表示绑定成功。

以后如果页面提示登录过期，点击该配置中的「重新登录」，再次完成上述验证即可。不需要手工复制 Cookie。

## 添加大V订阅

完成雪球或淘股吧登录，只代表 easy-stock 已保存对应平台的浏览器登录状态。还需要添加想关注的作者，系统才会自动采集文章。

1. 在浏览器中打开需要关注的雪球或淘股吧作者主页，并复制完整主页地址。
2. 回到 easy-stock，进入左侧的「大V复盘日记」。
3. 在「原文资料」页面展开「自动订阅与每日同步」。
4. 选择平台，并选择刚才完成登录的平台配置。
5. 可填写作者名称，然后将完整的作者主页地址粘贴到「粘贴大V主页地址」。
6. 点击「添加订阅」。
7. 点击「立即同步」可以马上检查新文章；之后系统会按照平台配置中的每日同步时间自动检查。

不同作者可以选择不同的平台配置。如果同一平台使用多个账号，也可以在系统设置中建立多套配置，再分别绑定作者。

> 请填写作者主页地址，不要填写搜索结果页或普通文章列表页。微信公众号目前不支持自动订阅历史文章，但仍可在「大V复盘日记」顶部粘贴具体文章链接进行导入。

## 常见问题

### 点击「保存并测试连接」后提示 401 或 403

通常表示身份验证或权限未通过。请依次检查：

- API Key 是否来自对应服务商的开放平台，粘贴时是否多了空格或漏了字符。
- 开放平台 API 账户是否有可用余额。
- 当前 Key 是否被删除、禁用或限制了模型权限。
- 服务商、API Base URL 和 API Key 是否属于同一家平台。

### 提示 404、模型不存在或无法调用

检查 API Base URL、接口协议和模型名是否正确。DeepSeek 使用 `https://api.deepseek.com`，Kimi 使用 `https://api.moonshot.cn/v1`，两者的接口协议都选择 `Chat Completions`。Kimi 用户可重新点击「获取模型」，选择账号当前可用的模型。

### 「获取模型」失败，但我已经填写了 Key

先检查网络、API 余额和 Base URL。获取列表失败不一定代表模型调用一定失败，也可以手动输入模型名后执行「保存并测试连接」，以真实测试结果为准。

### AI 分析长时间没有完成

个股长报告、持仓巡检和批量复盘本身需要较长时间。可以先使用其他功能，稍后回来查看结果。如果最终提示超时，可在「Hermes 模型运行时」中适当提高「模型响应等待时间」，或换用响应更快的模型。

### 已充值会员，为什么仍提示余额不足

请确认充值的是**开放平台 API 账户**，而不是网页或手机 App 会员。两类产品通常分别计费，余额不能直接通用。

### 点击「我已完成登录」后仍未识别登录状态

这通常表示平台网页还没有真正完成登录。请检查页面右上角是否已经显示自己的账号，并完成所有验证码、滑块或安全验证，然后再次点击「我已完成登录」。仍然失败时，关闭窗口后点击「重新登录」。

### 显示已登录，但文章同步失败

请检查：

- 登录状态是否已经过期，必要时点击「重新登录」。
- 订阅中填写的是否为该平台的作者主页地址。
- 订阅所选的平台配置是否与作者平台一致。
- 平台是否触发了验证码、访问频率限制或其他安全验证。

排查仍无结果时，可进入「系统设置 → 运行日志」，点击「打开日志目录」，将问题发生时间附近的日志文件提供给开发者。日志会隐藏模型密钥和登录凭据，但发送前仍建议自行检查其中是否包含不希望公开的信息。

## 密钥与账号安全

- API Key 只应粘贴到 easy-stock 的「模型 API Key」输入框，不要发送给任何人。
- 不要将完整 API Key、验证码、账号密码或登录截图提交到公开 Issue 或群聊。
- easy-stock 将模型密钥交给本机 Hermes 保存，设置页不会重新读取密钥明文。
- 雪球和淘股吧登录状态通过独立的内置浏览器会话保存在本机，不需要向 easy-stock 提供账号密码或手工复制 Cookie。
- 在公共电脑上使用后，请清除已保存的模型密钥和平台登录状态。
- 如果怀疑 API Key 泄露，请立即前往服务商开放平台删除旧 Key，并创建新 Key。
- 使用第三方模型和内容平台时，请遵守相应平台的服务条款、内容规则与访问限制。

easy-stock 的 AI 输出和第三方数据仅用于学习、研究与信息整理，不构成投资建议、收益承诺或交易依据。
