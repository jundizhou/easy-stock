## 实测发现与修正

1. 首轮压缩成功，但模型先返回非法 JSON 数值 `+2`，修复后仍返回不受支持的 `style_match="基本匹配"`，最终被校验拦截。补齐评分提示中的合法整数写法和完整枚举，没有放宽校验或自动替模型选等级。
2. Hermes 把每个新沙箱当作首次聊天，在结构化任务中注入 `/help` 和建立用户画像的引导，干扰 JSON 输出。仅在后台沙箱进程中抑制这一引导；交互聊天保留原行为。修正后的真实摘要未再附加该引导。
3. 第二轮模型已通过校验，但新增实测脚本复用了任务 ID，保存评分尝试时出现主键冲突。脚本改为每轮新建任务 ID、复制摘要检查点并加载旧草稿，与生产恢复流程一致。另将测试工作目录固定在隔离输出目录，避免随机目录引起配置标识变化而失去缓存复用资格。
4. 最后一轮恢复评分通过；随后直接复用两份已保存摘要，没有新增模型调用。三轮合计 11 次真实模型调用，聚合执行时间约 24 分 46 秒，运行时汇总 347,782 Token。最终通过属于修正后的恢复实测，并非首轮无重试成功。
