# 新闻事实与资料缺口的判断

2026-10-08 修复：个股分析不再把所有 `news` 事实强制改为推断，也不再要求至少两条支持依据才允许证据充分。持仓巡检、优化配仓及独立复评共享同一新闻判断规则。

## 判断范围

- 公司披露、可复算数据、可追溯报道分别保留原始来源类型。报道不能被改标成公告原文。
- 新闻有媒体出处、有效网页链接、发布时间及非标题内容时，允许模型根据实际内容评估其事实转述。`traceable` 只描述可检查的出处，不是媒体白名单或真实性认证；不自动把模型认定的有限、不足、观点或传闻升级为充分。
- 一条可靠报道可以支持一个限定事实；证据充分度由模型判断核心事实是否得到支持，程序检查核心判断和支持依据是否有可用来源。没有支持依据仍为不足，仅有标题、观点或出处缺失的核心依据仍为有限。
- “公司披露某报告期利润区间”“未来经营展望”“消息解释股价上涨”分别判断。年份、报告期、归母/扣非、累计/单季、金额及预测限定不得混用；转载同稿不视为多源独立验证。
- 公告抓取失败或仅缺正文属于资料限制，不能单独进入反证、主要风险、扣分项、减仓及优化理由。数字冲突、否认、更正和真实经营问题继续保留；集中度、估值和兑现风险各自评价。

## 数据传递

个股证据卡与持仓评分保留 `news_context`。优化的紧凑来源表增加可选 `news_context` 列，携带媒体、链接、发布时间、内容状态、可追溯性和有界摘录，避免压缩成 `news` 标签后再次降级。原始来源及全文仍保存在研究报告中。

深度研究的问题规划优先复用原文，可按公司、年份/报告期及事件关键词定向补公告；检索失败不等于新闻失实。标准研究保留现有资料处理流程，无额外强制联网或模型调用。

版本：研究提示 `stock-research-v9`、校验 `stock-research-validation-v4`、压缩 `evidence-pack-v8`、巡检提示 `portfolio-inspection-v5`、优化提示 `portfolio-optimization-prompts-v32`。股票组合评分权重和数值标尺未改变。

历史报告不覆盖。复用旧报告时，只能用保存的原模型输出和同一快照重新校验；不能把模型原本判断的不足强改为充分，也不延长复用窗口。旧模型生成的负面措辞需要重新分析才能更新，组合模型会按新规则区分其资料缺口与真实反证。

## 验证

离线回归覆盖可信报道及单条支持、出处缺失、仅标题、传闻/观点不升级、混合来源顺序、标准/深度个股研究、巡检/优化/复评的来源传递及历史不变性。测试使用固定模型输出验证程序链路和实际提示内容，不代表已经用真实模型验证所有措辞。

## 2026-10-09：预告的风险定位与正文保留

正式业绩预告/快报本身是公司披露。对已结束报告期的初步核算，可以用于判断当期盈利和增长；普通“未经审计、以定期报告为准”属于口径说明，不单独构成反证、扣分、配置限制或优先处理事项。尚未结束年度的经营展望、订单及量产预测仍按未来条件判断。不得由最大持仓比例放大普通披露进度，也不能要求先等季报再处理已知集中或现金流问题。

预告下修/更正、同口径数字冲突、异常核算或审计不确定性以及预告披露的亏损/下滑继续按实际影响评价。不能把常规未经审计声明等同于审计异常，也不能把所有预告视为与最终财报必然一致。

一次冻结资料核查发现：快照已保存最新预告正文，但较旧的调研记录、业务关键词与新闻先占据资料预算，模型仍称只有媒体标题。压缩现在优先保留最近的预告/快报，按财务数字、期间和限定提取原句；交易条件阶段也保留该正文，即使旧核心判断只引用了新闻。巡检和优化复评额外提供已有的最近预告摘录，允许据原始资料纠正旧摘要的缺原文说法，原报告保持不变。

本次提示版本为 `stock-research-v10`、`portfolio-inspection-v6`、`portfolio-optimization-prompts-v33`，压缩为 `evidence-pack-v9`。各阶段资料预算与评分权重不扩大。回归包含正文被旧调研和新闻挤出的场景、下修公告、旧摘要未引用正文以及可选的真实冻结资料审计和隔离模型复评。

验证结果：个股、巡检、优化及 HTTP API 模块测试通过。截图对应冻结研究的回放在核心和交易阶段均保留前三季度及单季归母利润、同比区间、未经审计说明，同时保留量价和财务来源，正文占用分别为 11,891/12,000 与 7,819/8,000 字节。交易阶段仅减少重复逐日行，完整窗口统计保留。使用原配置 `glm-5.3-flash` 的一次隔离巡检复评在 300 秒超时，未取得有效模型输出；此结果不能证明新规则下的实际风险措辞已经通过真实模型验证。


## 2026-10-09：优化调用容量（v34）

真实10股任务暴露了组合输入的22 KiB硬截断。优化各阶段现在先按原目标压缩，再允许48 KiB必要资料和64 KiB含纠错输入；个股证据预算及评分权重保持。新闻出处按共享列编码，摘录随档位调整，原文、真实反证与出处保留。真实模型还出现过risk仅填“预告未经审计”，该明确常规声明现在触发股票行局部纠错，不替模型编造风险。实际经营或异常审计问题继续保留。两轮隔离验证分别走通完整生成/复评及该错误的局部纠错/复评，详见[优化评估记录](portfolio-optimization-evaluation.md#提示v34丰富证据容量与恢复2026-10-09)。
